# X3FQuickLook

A macOS Quick Look Thumbnail Extension for Sigma X3F files.

## What this project was meant to do

The goal of this project was to make macOS Finder display proper photo
thumbnails for Sigma X3F RAW files, in the same way it displays
thumbnails for JPEG and other image formats.

The project was developed and tested on macOS 12.7.6 with Xcode 14.2.

## What it does

The Quick Look extension:

- recognizes Sigma X3F files;
- reads the X3F file structure;
- locates the embedded JPEG preview;
- extracts the JPEG from the X3F container;
- decodes it using Apple's ImageIO framework;
- provides the resulting image to Quick Look.

The extension is functional and Finder does invoke it to generate the
thumbnail.

## What it does not do

The thumbnail generated by the extension is not displayed by Finder as
a normal full-size image thumbnail.

Instead, Finder displays the generated image as a small thumbnail
inside the standard X3F document icon.

Therefore the project does not achieve its original goal of making X3F
files behave visually like normal image files in Finder.

## Why

The problem is not the extraction or decoding of the JPEG preview.

The X3F file is correctly recognized by the Sigma application as:

    com.sigmaphoto.photopro-x3f

However, the UTI registered by Sigma Photo Pro conforms to:

    public.data

rather than an image type such as:

    public.image

As a result, Finder continues to treat the X3F file as a generic
document/data file. The Quick Look Thumbnail Extension is called and
successfully produces an image, but Finder does not use that image in
the same way it uses thumbnails for files classified as images.

Changing the UTI registration would require modifying the registration
provided by Sigma Photo Pro. This was tested experimentally, but was
not pursued because it would involve altering a third-party
application and its code signature.

## Current status

**Functional, but incomplete.**

The project is kept here primarily as a record of the investigation
and as a possible starting point for future work.

The X3F parser and embedded JPEG extraction are functional, and the
Quick Look extension itself works. The remaining problem is the way
macOS Finder classifies and renders the X3F document.

## Requirements

- macOS 12.7.6 or later
- Xcode 14.2 or later
- Sigma X3F files
